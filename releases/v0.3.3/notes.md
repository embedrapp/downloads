## What’s New

- Agent sessions recover more reliably after reconnects, retries, long responses, and automatic context compaction.
- Long-running work now has clearer progress and reconnection markers, with fewer duplicated or missing turns.
- Added Embedr Access support and more reliable usage accounting when several requests begin at the same time.
- Project datasheet indexes can now be discovered directly by the agent, and unsupported encrypted PDFs produce clearer errors.
- PCB capability checks now recognize pad-only connections, and mechanical builds are more robust with complex CAD assemblies.
- Improved reliability across hosted agents, billing, analytics, and background services.
- Updated macOS packaging and signing support for current release infrastructure.

This release also includes performance, stability, and diagnostics improvements across the desktop and web agent experience.
