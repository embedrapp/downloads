## What’s New

- Automatic updates on Windows work again.
- Board tools work on Windows with KiCad 10 installed, and you can choose whether KiCad and SPICE simulation run locally or in the cloud in Settings.
- The 3D board viewer works without KiCad 10 installed.
- Large projects send everything the cloud tools need for layout, simulation and manufacturing checks.
- Long conversations are summarized faster, and the agent picks up where it left off instead of starting over.
- Board edits keep the solder mask on through-hole pads, and boards already affected are repaired on their next edit.
- Vias at the manufacturer's annular-ring limit now pass manufacturing checks instead of blocking your order.
- Mechanical snapshots show a model from every side.
- More reliable agent runs, project switching and new-board setup.
