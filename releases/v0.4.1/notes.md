## What’s New

- Large files you attach reach the agent in full, and stay available after a long conversation is condensed.
- Renaming a project keeps its chats, checkpoints and settings.
- The agent checks the datasheets you attached before saying one is missing, and shows each one's file name.
- When the agent asks you for a value, it offers real choices and points you to typing your own.
- Helpers the agent starts keep working while the agent waits on a long command.
- Before editing a file, the agent checks that nobody changed it since it last looked, so your own edits are never overwritten.
- Long Claude replies no longer get cut off and restarted partway through.
- Assembly order checks work again in the installed app.
- Slow mechanical builds finish instead of starting over, and a stuck board screenshot no longer blocks the project.
- Datasheet processing recovers from interruptions and shows clear error messages.
- On Windows, chat progress saves even while antivirus or sync tools briefly lock files, and Embedr says why PCB tools could not start.
- OpenCode account errors explain how to fix them instead of offering Retry.
- Shared projects show the right schematic preview, and the Free plan works again after a checkout that did not go through.
