## What’s New

- Search finds files by name as well as by what's inside them.
- The agent keeps going when it still has work it can do, instead of stopping with a progress report.
- Advanced PCB Automation keeps paid routing results, even when a job outlasts your sign-in, and can give the same job more time instead of starting over.
- The agent picks the right router for your board, reports differential pairs the autorouter left uncoupled, and finishes the last few connections instead of starting the routing again.
- Clearance rules between two groups of nets now apply only between those groups, so routing is no longer held to a wider clearance than your rules ask for.
- Library parts install on large projects.
- Building your firmware keeps the board your project targets.
- Reopening a board shows its last design rule check at once when nothing changed.
